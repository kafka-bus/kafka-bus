# Kafka Bus Partitions

[![Latest Version on Packagist](https://img.shields.io/packagist/v/kafka-bus/partitions.svg?style=flat-square)](https://packagist.org/packages/kafka-bus/partitions)

Partition and offset inspection/administration API for [Kafka Bus](https://github.com/kafka-bus/kafka-bus). Lists partitions for a set of topics and lets you manually set consumer offsets — independent of any particular consumer/worker implementation.

## Installation

You can install the package via composer:

```bash
composer require kafka-bus/partitions
```
